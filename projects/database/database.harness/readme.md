# database-harness

测试与基准的判定协议 crate。负责七件事：语料身份（seed / count / 摘要）、已知差异台账（登记、匹配、未登记、信号变化、陈旧条目）、观测比对与归类、基准统计与报告行、报告信封、grammar 驱动的模糊输入生成（确定性 PRNG、复现信封与收缩状态机，语法内容由调用方提供）、门禁判定（套件计数汇总与 floor 判定，测试输出解析留在产品仓）。

## 不做的事

- 不解析线协议，不实现 SQL 或命令语义。
- 不生成任何期望值；期望值始终由真实外部引擎、官方语料或冻结基线提供。

## Feature

| Feature | 默认 | 说明 |
|---------|------|------|
| `charts` | — | 经 `plotter-chart` 把基准报告行渲染为分组柱图 SVG，判定核心默认零绘图依赖 |

## 依赖方向

固定为 `database-harness -> database-types`。本 crate 不反向依赖 `database` 门面，也不依赖任何产品 crate。

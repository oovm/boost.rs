# Jinja

A parser for Jinja2 templates written in Rust using the `data.text` framework.

## Features

- Parses Jinja2 syntax
- Supports standard Jinja2 constructs
- Integration with `data.text` family (LSP, highlighting, etc.)

## Usage

Add this to your `Cargo.toml`:

```toml
[dependencies]
data-text-jinja = "0.0.4"
```

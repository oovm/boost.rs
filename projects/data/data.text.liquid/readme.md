# Liquid

A parser for Liquid2 templates written in Rust using the `data.text` framework.

## Features

- Parses Liquid2 syntax
- Supports standard Liquid2 constructs
- Integration with `data.text` family (LSP, highlighting, etc.)

## Usage

Add this to your `Cargo.toml`:

```toml
[dependencies]
data-text-liquid = "0.0.4"
```

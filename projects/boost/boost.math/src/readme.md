# `boost-math`

Boost 家族的数学能力：数学对象与运算意义归本 crate，集合表示、存储与领域语义留在各自 owner。

| 模块 | 内容 | 当前状态 |
|------|------|----------|
| `bigint` | 有符号任意精度整数语义：符号、规范零、比较、加减乘、受检除法/余数 | 首批实现落地中 |
| `graph_theory` | 消费图访问能力的图论算法：拓扑序、连通分量、加权路径 | 首批实现落地中 |
| `numeric` | 自有标量数值内核（`sqrt`/`ln`/`exp`），供 random 等下游单向消费 | 由 `boost-random` 迁入 |

边界：

- 图容器、顶点/边身份、邻接访问与存储布局归 `boost-collection`，本 crate 只消费其访问能力。
- 密码方案、密钥生命周期、清理与端到端侧信道验收归 `boost-crypto`；本 crate 只提供数学内核。
- 可变长度 `BigInteger` 允许变时分支与堆分配，不得直接承接秘密标量或私钥运算。

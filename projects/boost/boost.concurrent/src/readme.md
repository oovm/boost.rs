# `boost-concurrent`

并发原语：协作式取消、计数等待组与固定线程执行器。

- [`Cancel`]：可克隆的布尔令牌；任意克隆取消后，所有克隆都观察到已取消。
- [`Waiter`]：`add` / `done` / `wait` 计数等待组，归零唤醒。
- [`Pool`]：固定线程执行器；`spawn` 提交 `'static` 任务，`close` 排空并回收；
  任务恐慌被隔离在工作线程内。
- [`threads`]：线程数上限，显式请求按硬件并发度裁剪，`0` 取硬件并发度。

需要借用数据、按输入序合并的作用域并行归 `boost-parallel`。

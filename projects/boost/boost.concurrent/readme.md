# `boost-concurrent`

Boost 家族的并发原语：协作式取消、计数等待组与固定线程执行器。

| 条目 | 内容 | 当前状态 |
|------|------|----------|
| `Cancel` | 可克隆的布尔取消令牌，长任务在分块边界自行退出 | 已实现 |
| `Waiter` | 计数等待组：`add` / `done` / `wait`，归零唤醒 | 已实现 |
| `Pool` | 固定线程执行器：`spawn` 提交 `'static` 任务、`close` 排空并回收 | 已实现 |
| `threads` | 线程数上限：显式请求按硬件并发度裁剪，`0` 取硬件并发度 | 已实现 |

边界：

- 只依赖 `std` 线程、互斥量与通道，不引入全局运行时、不接管工作窃取。
- 需要借用数据的作用域并行（`map` 按输入序合并）归 `boost-parallel`，本 crate 只提供原语。
- 任务恐慌被隔离在工作线程内，不会击穿线程池；恐慌会被吞掉，调用方需要结果时应自行回传错误。

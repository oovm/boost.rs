# `boost-parallel`

Boost 家族的确定性作用域并行：借用切片、按输入顺序合并、支持协作式取消。

| 条目 | 内容 | 当前状态 |
|------|------|----------|
| `for_each` | 并行遍历切片元素，副作用顺序不作保证 | 已实现 |
| `map` | 并行映射，输出按输入下标排序，与串行结果同序 | 已实现 |
| `for_each_range` | 按动态分块遍历下标区间，块边界检查取消令牌 | 已实现 |
| `threads` / `Cancel` | 复用 `boost-concurrent` 的线程数策略与取消令牌 | 已实现 |

边界：

- 只使用 `std::thread::scope` 借用调用方数据，不要求 `'static`，也不使用 `unsafe`。
- 不做工作窃取：分块由共享游标动态领取，块大小取输入长度的 1/(8×线程数)，兼顾均一大块与长短不齐的区间。
- 提前退出只在分块边界生效；已开始的块会完整执行，因此输出是"某一前缀"而不是任意子集。
- 需要常驻线程、`'static` 任务或等待组时使用 `boost-concurrent` 的 `Pool` 与 `Waiter`。

# `boost-collection`

Boost 家族的规则集合能力：逻辑模型、访问能力、表示布局与存储载体分开描述。当前只交付**首个内存实现**（自有、连续行主序、`usize` 范围），不把连续、dense 或常驻内存写成 ArrayND 的普遍前提，也不引入 `ndarray`/`nalgebra`。

## 分层

| 层 | 内容 | 当前状态 |
|----|------|----------|
| 逻辑模型 | 规则 N 维坐标域、shape、坐标到元素的对应关系 | 合同已冻结，代码以内存实例表达 |
| 访问能力 | 读、写、遍历、越界与失败方式 | 内存实现提供引用式访问与检查式失败；二维只读/可写视图提供坐标映射，可写要求独占与单射 |
| 表示与布局 | 行主序、strided、分块、稀疏 | 连续行主序；二维 ROI 与转置以视图表达 |
| 存储载体 | 自有/借用内存、映射文件、分页磁盘、设备 | 仅自有内存 |

逻辑元素数与已分配槽数、逻辑遍历序号与物理地址是不同事实；稀疏缺省、shape 变更、视图失效与 I/O 失败语义尚未进入代码。二维视图用 `shape`、`offset`、`strides` 描述坐标映射；跨行有间隙或转置的视图不伪造连续 `slice`，需要紧凑缓冲时调用方显式物化。可写视图只能由 `&mut` 独占借出，并在构造时校验坐标映射单射（零 stride、重叠或溢出一律拒绝），不以地址在界内证明无别名。等第二种真实表示出现再抽能力 trait，不先造 God trait 或空后端。

## 三个作者面

| 类型 | 形状位置 | 存储 | 适用 |
|------|----------|------|------|
| `ArrayND<T, N>` | 运行时构造（`N` 是轴数） | `Vec<T>` 连续区 | 维数固定、各轴长度运行时确定 |
| `Array2D<T, ROWS, COLUMNS>` | 编译期类型参数 | `[[T; COLUMNS]; ROWS]` | 小尺寸二维、形状属于类型合同 |
| `Array3D<T, D1, D2, D3>` | 编译期类型参数 | `[[[T; D3]; D2]; D1]` | 小尺寸三维、形状属于类型合同 |

稳定 Rust 不允许元组作为 const 泛型参数，因此 `Array2D<f32, (3, 3)>` 不成立。需要元组书写时用宏：

```rust
use boost_collection::array;

type Grid = array!(f32, (3, 3));

let mut grid = Grid::filled(0.0);
grid[[1, 2]] = 5.0;
assert_eq!(grid.shape(), [3, 3]);
```

```rust
use boost_collection::array;

type Cube = array!(f32, (2, 3, 4));

let cube = Cube::filled(0.0);
assert_eq!(cube.shape(), [2, 3, 4]);
```

`array!(f32, 3, 3)` 与 `array!(f32, 2, 3, 4)` 分别和二维、三维元组写法等价，展开结果都是普通 `Array2D` / `Array3D` 类型。

## 图

图以逻辑能力描述，不以邻接表定义本体：

| 能力 | 内容 | 当前实现 |
|------|------|----------|
| `GraphRead` | 方向、顶点/边计数、顶点/边枚举、端点 | 内存图与 CSR |
| `OutgoingEdges` | 出边枚举，不要求反向索引 | 内存图与 CSR |
| 拓扑序 | `topological_order` 只要求出边与端点 | 两种表示共用同一实现 |

- 顶点身份是调用方给出的键，不要求连续整数；边标识在同一图内有效，平行边各有一条独立标识，自环允许但构成环。
- 无向边是一条逻辑边，两个方向都是出边；无向自环在出边枚举中出现一次。
- 内存图不可变结构、出边索引常驻内存；CSR 在构建时物化一次，之后只读。
- 空图返回空序，环（含自环）返回 `GraphError::Cycle`，无向图拒绝方向遍历。
- 入边能力、删除后的标识失效、快照可见性、结构修改与图属性映射尚未提供；plotter 的真实图消费者尚未接入。

## 不变量

- `ArrayND` 的 `N` 是轴数，不是任何一轴的长度；各轴长度只在构造时确定，之后不变。
- 逻辑元素数严格等于各 extent 的乘积；零 extent 先识别，空数组仍保留各轴信息（`[0, 5]` 与 `[3, 0]` 都为 0 元素但形状不同）。
- 形状乘积、索引偏移与容量检查全部使用检查算术；坐标先逐轴验界再计算偏移。
- 元素可写，但不提供行级 `push`/`pop`，也不交出能改变缓冲长度的入口；`as_mut_slice` 只能改元素。
- 初始化不要求 `T: Default`/`T: Clone`；构造失败或 panic 时已初始化元素恰好释放一次。
- `ArrayND` 遍历与 `into_vec` 都按行主序；跨行有间隙的语义留给后续视图模型，不在索引路径隐式分配或复制。

## 边界

- 二维只读与可写视图支持整表、矩形 ROI 与行列转置；可写视图由独占借用产生并校验单射。`ArrayND::reshaped` 复用同一缓冲，按行主序线性化后套用新形状，可改变 rank 但必须保持元素数。三维视图与非 affine（如分块）布局尚未提供。
- 稀疏、分块、CSR 等表示与映射文件/分页/设备载体尚未交付；不提供 `backend = disk` 之类标签冒充支持。
- 邻接表、文档列表、变长字节串等真正不等长的数据保留分段语义，不补成矩形。
- 矩阵运算、张量执行、图语义、数据库列语义与 GPU 布局仍归各领域 owner。
- 当前以 `std` 为宿主；`no_std + alloc` 目标尚未取证，不声称已支持。
